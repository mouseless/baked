Monolith

Monolith recipe is the default backend recipe provided by Baked which includes necessary layers and feature implementations for any backend application.

To create an application from this recipe, use Monolith() extension of Bake class directly in Program.cs.

Bake.New
    .Monolith(
        business: c => c.DomainAssemblies([...])
    )
    .Run();

Changing Defaults

Use options: to change a default feature of this recipe, or to add a theme which also adds the UI layer;

Bake.New
    .Monolith(
        business: c => c.DomainAssemblies([...]),
        options: o =>
        {
            o.Database(c => c.PostgreSql());
            o.Theme(c => c.Default(index: r => r.Index(), routes: [...]));
        }
    )
    .Run();

Default database is SQLite, which requires Database:Sqlite:FileName setting unless a file name is given, e.g., o.Database(c => c.Sqlite("app.db"))
